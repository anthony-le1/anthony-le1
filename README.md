## 🇪🇸 Sobre mí

Estudiante de último semestre de **Tecnología Superior en Desarrollo de Software** en la Escuela Politécnica Nacional (ESFOT), con experiencia real en un entorno de producción gubernamental. Diseñé, construí y desplegué de forma independiente una plataforma institucional completa (Full Stack), cubriendo arquitectura, backend, frontend, seguridad e integración de sistemas.

Me interesa el desarrollo de software con enfoque en arquitectura sólida, seguridad y sistemas que escalan sin reescribirse.

### 🚀 Proyecto destacado — DGAC_FICHAS (V 4.0)

Plataforma institucional en producción para la gestión de certificaciones aeronáuticas nacionales, desarrollada durante mi práctica preprofesional en la **Dirección General de Aviación Civil (DGAC)**.

- Arquitectura MVC con **.NET Framework / C#**, base de datos **PostgreSQL**, desplegada en **IIS**.
- Panel administrativo con asignación de permisos granulares por trámite, configurable desde la interfaz sin tocar código ni base de datos.
- Auditoría de seguridad propia con **Kali Linux** y **OWASP ZAP**: identificación y corrección de vulnerabilidades críticas.
- Arquitectura diseñada para escalar de 2 a 50+ tipos de trámite sin reescribir el núcleo, documentada formalmente para la institución.
- Integración de sistemas independientes bajo un mismo portal, en coordinación con el equipo de Ingeniería Aeronáutica.
- Código fuente institucional (no público, por confidencialidad del sector gubernamental).

🔗 En producción: [apps.aviacioncivil.gob.ec/tramitesdgac](https://apps.aviacioncivil.gob.ec/tramitesdgac/)

## 🇺🇸 About me

Final-semester student of the **Associate Degree in Software Development** at Escuela Politécnica Nacional (ESFOT), with hands-on experience in a real government production environment. I independently designed, built, and deployed a complete institutional platform (Full Stack), covering architecture, backend, frontend, security, and systems integration.

I'm interested in software development focused on solid architecture, security, and systems that scale without being rewritten.

### 🚀 Featured project — DGAC_FICHAS (V 4.0)

Institutional platform in production for managing national aeronautical certifications, built during my professional internship at the **Directorate General of Civil Aviation (DGAC)**.

- MVC architecture with **.NET Framework / C#**, **PostgreSQL** database, deployed on **IIS**.
- Administrative panel with granular, per-procedure permission assignment, configurable from the interface without touching code or the database.
- Independent security audit using **Kali Linux** and **OWASP ZAP**: identification and remediation of critical vulnerabilities.
- Architecture designed to scale from 2 to 50+ procedure types without rewriting the core, formally documented for the institution.
- Integration of independent systems under a single portal, coordinated with the Aeronautical Engineering team.
- Institutional source code (not public, due to government-sector confidentiality).

🔗 Live: [apps.aviacioncivil.gob.ec/tramitesdgac](https://apps.aviacioncivil.gob.ec/tramitesdgac/)
